## 📖 Overview | 概述

**[EN]** This repository hosts two complementary research reports on **"The Economic Heavenly Way" (Tiandao Jingji)**. Both reports formalize Thierry Rebour's *Rent Extraction Theory* using **Clifford Algebra Cl(6,6)** to model complex economic systems as discrete information systems. The research demonstrates that the economy obeys a universal topological invariant ($64 \rightarrow 20$). Applied to post-2018 China, the model diagnoses the attainment of a "Nodal Phase" (exhaustion of the land-based growth engine) and proposes the **Territorial Regeneration Rent (TRR)** as the only topologically permitted transition operator to avoid systemic collapse (retropolarity) and initiate a new cycle of sustainable growth.

**[ZH]** 本仓库托管了两份关于 **"经济天道"** 的互补研究报告。两份报告均利用**克利福德代数 Cl(6,6)** 将蒂埃里·雷布尔（Thierry Rebour）的*赎买理论*形式化，将复杂的经济系统建模为离散信息系统。研究证明，经济系统遵循普适的拓扑不变量（$64 \rightarrow 20$）。应用于2018年后的中国，该模型诊断出系统已达到"节点"（土地驱动型增长引擎的耗尽），并提出 **"领土再生租金"（RRT）** 作为唯一在拓扑学上被允许的过渡算子，以避免系统性崩溃（逆极化）并启动新的可持续增长周期。

## 💡 Core Concepts | 核心概念

| English | Chinese | Description / 描述 |
| :--- | :--- | :--- |
| **Rent Extraction Theory** | 赎买理论 | The foundational theory by T. Rebour, modeling the transfer of latent "Value" into monetized "Wealth". / 雷布尔的基础理论，建模潜在的"价值"向货币化"财富"的转移。 |
| **Clifford Algebra Cl(6,6)** | 克利福德代数 Cl(6,6) | The mathematical framework used to map the 64 economic configurations into 20 stable attractors. / 用于将64种经济构型映射为20个稳定吸引子的数学框架。 |
| **The $64 \rightarrow 20$ Invariant** | $64 \rightarrow 20$ 不变量 | A universal topological law also observed in particle physics, the genetic code, and correlative Chinese thought (Yi Jing, Wuxing). / 在粒子物理学、遗传密码和中国关联性思维（易经、五行）中也可观察到的普适拓扑定律。 |
| **Nodal Point** | 节点 | The systemic threshold reached when the easily mobilizable stock of Value is exhausted. / 当易于调动的价值储备耗尽时达到的系统阈值。 |
| **Stasis** | 停滞 | An absorbing state where the system is blocked, and wealth destruction no longer recreates Value. / 系统被阻塞的吸收态，此时财富的毁灭不再重新创造价值。 |
| **Territorial Regeneration Rent (TRR)** | 领土再生租金 (RRT) | The proposed operational solution: a mixed transition operator ($T_{\text{mixed}}$) to regenerate degraded spaces and restart the economic cycle. / 提出的操作化解决方案：一种混合过渡算子，用于再生退化空间并重启经济周期。 |
